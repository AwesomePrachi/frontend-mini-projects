# Frontend Mini Projects

A collection of small frontend projects built to practice and apply web development concepts through hands-on development.

These projects focus on building interactive web interfaces using HTML, CSS, and JavaScript while applying concepts such as DOM manipulation, event handling, browser APIs, form handling, and asynchronous JavaScript.

5. Testing the application

Projects become progressively more complex as I apply new concepts and techniques.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/AwesomePrachi/frontend-mini-projects.git
```

Move into the repository:

```bash
cd frontend-mini-projects
```

For HTML, CSS, and JavaScript projects, open the project's `index.html` file in a browser.

If a project requires a local development server, follow the setup instructions provided in that project's README.
